使用說明

經費管理系統操作手冊

依系統導覽順序，說明專案、預算、核銷、流用、報表與備份的操作。

適用時機：第一次使用或查找日常操作。

事前準備：在 Windows 啟動經費管理系統。

1開始使用

依序啟動系統並完成首次設定。

啟動與停止

  1. 雙擊「啟動經費管理.bat」

    在 Windows 檔案總管中執行。

  2. 等待瀏覽器開啟系統頁面

    系統預設使用本機網址 http://127.0.0.1:8765。

  3. 要停止服務時，關閉啟動程式的命令視窗

本系統以 SQLite 儲存資料，供單機、單人使用。

初次設定順序

  1. 建立專案

    到 所有專案 建立專案並填寫基本資料。新建專案時，系統會自動建立部分預設選項。

  2. 確認選項

    到專案的 選項資料 確認預設選項，並視需要補充或調整。

  3. 載入預算

    到 匯入預算明細 載入預算明細，或手動新增。預算匯入可確認並新增檔案中尚未建立的選項；核銷與流用匯入則須使用已建立的選項。

  4. 核對後開始登錄

    到 預算明細 核對資料，再開始登錄核銷與經費流用。

何時需要使用選用套件安裝工具？

一般操作不需要另外執行 Install-optional-packages.bat。需要匯出 PDF、在 Email 報告附上 PDF，或寄送 Email 報告，但對應套件在啟動時被略過、缺少或版本不符合需求時，可使用此工具；要更新已安裝的選用套件時也可使用。

  1. 檢查專案資料夾是否已有 .venv 資料夾。
  2. 若已存在，先關閉系統；若不存在，先執行「啟動經費管理.bat」讓啟動流程建立環境，待系統啟動後關閉。
  3. 雙擊 Install-optional-packages.bat，依選單選擇 PDF、Email 或全部安裝／更新。

2所有專案

在所有專案頁建立、瀏覽及匯出專案。

所有專案 提供「執行中」、「未執行」、「已完成」及「總覽」分頁，可新增專案或瀏覽專案內容。

  • 專案狀態依執行起日、迄日及目前日期判定。
  • 未完成且距離迄日三個月內的專案會顯示提醒。
  • 專案清單可依狀態匯出為 Excel、Markdown 或 PDF。

建立專案時請填妥：

  • 專案名稱、執行單位
  • 專案編號：不可與其他專案重複。
  • 執行期間：決定專案狀態，核銷與流用日期也須落在這段期間內。
  • 專案經費總額：預算明細合計不可超過此金額，也是執行率的分母。

3經費總覽

查看專案執行率、彙整表、進度圖及筆記。

兩種執行率

首頁與 經費總覽 並列兩種執行率，兩者皆以專案經費總額為分母。

真實執行率

以已填登錄日期且未作廢的核銷金額計算。

用途：供報告使用。

預估執行率

納入所有未作廢核銷金額（含待核銷）。

用途：觀察目前規劃狀況。

彙整表

  • 依經費類別與屬性：分列流用後預算、已核銷、待核銷、可用餘額及含待核銷執行率，保留「類別小計」。
  • 依單位：分列已核銷、待核銷、可用餘額、含待核銷執行率及查看操作。

可用餘額 ＝ 流用後預算 － 已核銷 － 待核銷

執行率 ＝（已核銷 ＋ 待核銷）÷ 流用後預算分母為 0 時顯示「—」。

每月進度圖與其他區塊

  • 每月進度圖依專案執行起訖月份連續呈現真實執行率。待核銷沒有登錄日期，因此不列入月圖。
  • 頁面亦提供依經費類別與屬性彙整、依單位彙整、待核銷明細及專案筆記。筆記會儲存在系統資料庫。

4預算明細

核對每筆預算及可用餘額。

預算明細

每筆預算明細包含經費類別、單位、經費屬性、預算科目及初始預算。明細表分列以下金額：

欄位計算方式
流用後預算初始預算加上流入、減去流出後的預算。
已核銷有登錄日期且未作廢的金額。
待核銷未填登錄日期且未作廢的金額。
可用餘額見下方公式。

可用餘額 ＝ 流用後預算 － 已核銷 － 待核銷

  • 專案預算明細合計可以低於專案經費總額，但不可超過；尚未編列金額可在預算明細頁查看。
  • 預算科目可能因核銷而超支，之後可透過流用調整。

5核銷紀錄

登錄核銷並辨認已核銷、待核銷與作廢紀錄。

核銷紀錄 可新增或編輯核銷明細。每列代表一筆經費明細；多筆明細可共用批次說明及登錄日期。

填寫規則

  • 登錄日期與憑證日期可留白。登錄日期留白時標示「待核銷」，但該筆仍納入經費控管。
  • 日期須符合專案執行期間；憑證日期不可晚於登錄日期。
  • 付款對象及分配金額可不填；若填寫，兩者須成對，分配金額合計須等於核銷金額。
  • 作廢紀錄保留供查核，但不計入有效核銷統計。
沒有相符的預算明細時

系統會先詢問是否建立初始預算為 0 元的明細，再儲存核銷。超過專案或相關經費上限時，系統會拒絕儲存。

檢視與批次操作

可依「待核銷」、「已核銷」、「作廢」或「總覽」分頁查看資料，並使用批次「刪除」、「作廢」或「復原」功能。

6經費流用

管理規劃中與已流用的經費轉移。

經費流用 記錄同一專案、同一經費類別內的預算流出與流入，可跨單位或預算科目。新增時依序填寫日期、經費類別、流出項目、流入項目及金額。流用日期須在專案執行期間；已流用資料的流出與流入經費屬性須相同。

每筆流用有兩個彼此獨立的狀態：

狀態一：執行進度
規劃中→已流用

補齊資料並通過檢查後，可由規劃中改為已流用。

狀態二：鎖定
未鎖定⇄已鎖定

已鎖定紀錄不可編輯或刪除。

規劃中已流用
資料完整度可先記錄已知資訊。須補齊必要資料，並通過額度與經費屬性檢查。
額度流出項目及正數金額填妥時圈存可用額度；資料未填齊時不圈存。流出金額不得超過扣除其他規劃圈存後的可用餘額。
統計與報表不列入實際經費統計及正式報表。列入總額、流用科目變更及正式報表。

檢視與批次操作

  • 頁面提供「總覽」、「未鎖定」、「已鎖定」及「規劃中」分頁。
  • 可批次刪除、鎖定與解鎖。
  • 批次解鎖及可能造成預算明細透支的刪除會要求確認。
  • 選取項目中若有已鎖定紀錄，刪除會被拒絕。

7補充保費估算

用選定科目的預算餘額估算補充保費。

在 補充保費估算 選取要估算的預算科目。

估算金額 ＝ 所選科目的預算餘額合計 × 共用倍率預設倍率為 2.11%，可調整。結果四捨五入至整數元，供預算管理參考。

8流用科目變更

查詢已流用紀錄對預算科目的影響。

  1. 在 流用科目變更 填寫起日、迄日，或只填其中一個日期。
  2. 點選 查詢，檢視預算科目變更前、變更後及增減金額。
  3. 需要留存時，點選 匯出此次查詢（Excel）。

只填一個日期即查該日；填起訖日期則合併區間內所有有效流用。查詢只列出預算總額有變動的科目，依經費類別分類並合併各單位金額。

變更前為起始日前的預算，變更後為結束日流用完成後的預算；規劃中的流用不列入正式報表。

9選項資料

管理專案使用的經費類別、單位、經費屬性及預算科目。

專案建立時，系統會自動建立部分預設選項（例如預設經費類別）。在 選項資料 確認現有選項，並管理專案使用的經費類別、單位、經費屬性及預算科目。

預算匯入

可在預覽後確認新增缺少的選項。

核銷、流用匯入及手動新增

須使用現有選項；缺少時請先到「選項資料」新增。

刪除前請注意

刪除預算明細或選項前，系統會顯示相依資料及刪除影響。以下情況系統會阻止刪除：

  • 有核銷紀錄（包括作廢紀錄）
  • 有已流用紀錄
  • 有已鎖定的規劃流用
  • 刪除會造成經費上限不足

可刪除時，確認前會列出將一併移除的資料。

10Email 經費報告

設定收件人、預覽郵件並確認寄送。

Email 功能位於個別專案內。第一次使用前，請先依 Gmail SMTP 設定教學 完成寄件設定。

  1. 設定 SMTP 寄件服務及收件人
  2. 選擇收件對象

    單位收件人固定收到其所屬單位資料。

  3. 設定主管資料範圍

    主管的資料範圍可在寄送時選擇。

  4. 檢視郵件預覽
  5. 確認寄送
  • 每次報告涵蓋專案開始日至寄送當下的累計紀錄，不會按月自動寄送。
  • 每封郵件可附上所選格式的專案報表。
  • 寄送結果會逐位記錄；刪除寄送紀錄不會撤回已寄出的郵件。
  • SMTP 設定全系統共用。密碼或應用程式專用密碼儲存在 Windows 安全憑證區，不存於 SQLite。同一 Windows 使用者帳戶下搬移專案資料夾可沿用設定；複製到其他電腦時需在新電腦重新輸入密碼。
預覽不會寄出

預覽郵件不會實際寄送。只有在檢視內容並確認寄送後，系統才會發出郵件。

11匯入資料

預覽檔案檢查結果，確認後再匯入。

系統支援 .xlsx、.xlsm 及 .csv 檔案匯入；Excel 檔案讀取第一個工作表。匯入前選擇資料類型並檢查預覽。預覽不會寫入資料；確認匯入後才會新增紀錄。

類型檢查與行為
預算檢查欄位、選項及預算上限。確認匯入時，資料所需的新選項會同步建立在「選項資料」。
核銷可選擇每列建立獨立批次，或合併批次說明與登錄日期皆相同且非空白的資料。
流用正式金額欄名為「流用金額」；檢查流出／流入項目、經費屬性及可用餘額。預覽有錯誤時不可匯入；檔案內有重複資料時，確認後仍可繼續匯入。

欄名檢查（三種匯入共用）

  • 空白欄名且整欄無資料時略過；有資料時指出欄位位置。
  • 未知欄名、重複欄名、同義欄位衝突或資料列欄數多於表頭時，會顯示錯誤並阻擋匯入。

12匯出資料

選擇範圍與格式，產生精簡報表。

  1. 選擇範圍

    在 匯出資料 選擇專案彙總、單位資料或兩者。

  2. 選擇格式

    Excel、Markdown 或 PDF。PDF 會開啟預覽，可使用瀏覽器列印或另存為 PDF。

  • 首頁另可依專案狀態匯出專案清單。
  • 規劃中的流用不納入正式匯出報表。
  • 流用科目變更匯出為單一 Excel 活頁簿，包含總表及每個經費類別的工作表，依類別、屬性與科目分列並附合計。
匯出檔不能直接匯回

匯出檔定位為精簡報表。新增資料請使用匯入範本。

13備份與還原

下載備份，並在需要時確認還原影響。

  • 使用側邊欄的 下載資料庫備份 定期備份。
  • 搬移到另一台電腦時，請備份並移轉資料庫。
還原會完整取代目前資料

還原備份會以備份檔完整取代目前資料；操作前請確認選取的是正確備份檔。

不要在系統運作時使用其他程式直接修改資料庫。

14表單與畫面操作

使用鍵盤捷徑和表格控制項完成日常操作。

操作說明
Ctrl + S儲存表單。
Esc 或「關閉表單」關閉表單；若有未儲存內容，系統會先詢問。
  • 日期使用西元年格式；金額以新臺幣整數元輸入與保存。
  • 表格可調整每頁筆數；多數表格可點擊標題排序，也可設定欄位對齊。
  • 主題設定可切換淺色或深色、設定自訂顏色、上傳或移除背景圖片，以及更換品牌圖示。

15常見問題

依畫面現象檢查常見操作問題。

匯入預覽出現欄名錯誤怎麼辦？
現象
預覽顯示未知、重複或衝突欄名，不能匯入。
原因
檔案欄名不符合匯入範本，或資料欄數超過表頭。
解法
依預覽指出的位置修正欄名與欄數，再重新預覽；新增資料請使用匯入範本。
刪除預算明細或選項被阻止怎麼辦？
現象
確認視窗標題顯示「無法刪除」，並列出阻擋原因。
原因
可能已有核銷、已流用或已鎖定的規劃流用，或刪除會使經費上限不足。
解法
使用「檢視相關資料」查看原因；受保護帳務資料不能一併刪除。
Email 預覽後為什麼沒有寄出？
現象
已看過郵件預覽，但收件人沒有收到報告。
原因
預覽不會實際寄送。
解法
核對收件人與內容後，明確執行「確認寄送」；再查看逐位寄送結果。
