使用說明

經費管理系統操作手冊

本手冊說明如何建立專案、管理預算與經費紀錄，以及使用匯入、報表、Email 和備份功能。

1. 開始使用

啟動與停止

  1. 在 Windows 檔案總管雙擊「啟動經費管理.bat」。
  2. 等待瀏覽器開啟系統頁面；系統預設使用本機網址 http://127.0.0.1:8765。
  3. 要停止本機服務時，關閉啟動程式的命令視窗。

本系統以 SQLite 儲存資料，供單機、單人使用。

何時使用選用套件安裝工具

一般操作不需要另外執行 Install-optional-packages.bat。需要匯出 PDF、在 Email 報告附上 PDF，或寄送 Email 報告，但對應套件在啟動時被略過、缺少或版本不符合需求時，可使用此工具；要更新已安裝的選用套件時也可使用。

先檢查專案資料夾是否已有 .venv 資料夾：若已存在，先關閉系統，再雙擊 Install-optional-packages.bat；若不存在，先執行「啟動經費管理.bat」讓啟動流程建立環境，待系統啟動後關閉，再雙擊安裝工具。依選單選擇 PDF、Email 或全部安裝／更新。

初次設定順序

  1. 到「所有專案」建立專案並填寫基本資料。新建專案時，系統會自動建立部分預設選項。
  2. 到專案的「選項資料」確認預設選項，並視需要補充或調整。
  3. 到「匯入預算明細」載入預算明細，或手動新增。預算匯入可確認並新增檔案中尚未建立的選項；核銷與流用匯入則須使用已建立的選項。
  4. 到「預算明細」核對資料，再開始登錄核銷與經費流用。

2. 專案管理

「所有專案」提供「執行中」、「未執行」、「已完成」及「總覽」分頁，可新增專案或瀏覽專案內容。專案狀態依執行起日、迄日及目前日期判定；未完成且距離迄日三個月內的專案會顯示提醒。

專案清單可依狀態匯出為 Excel、Markdown 或 PDF。建立專案時請填妥專案名稱、唯一專案編號、執行單位、執行期間及專案經費總額。

3. 預算明細與選項資料

預算明細

每筆預算明細包含經費類別、單位、經費屬性、預算科目及初始預算。明細表分列流用後預算、已核銷、待核銷及可用餘額；已核銷為有登錄日期且未作廢的金額，待核銷為未填登錄日期且未作廢的金額，可用餘額＝流用後預算－已核銷－待核銷。專案預算明細合計可以低於專案經費總額，但不可超過；尚未編列金額可在預算明細頁查看。預算科目可能因核銷而超支，之後可透過流用調整。

選項資料

專案建立時，系統會自動建立部分預設選項（例如預設經費類別）。在「選項資料」確認現有選項，並管理專案使用的經費類別、單位、經費屬性及預算科目。預算匯入可在預覽後確認新增缺少的選項；核銷與流用匯入及手動新增資料須使用現有選項，缺少時請先到「選項資料」新增。

刪除預算明細或選項前，系統會顯示相依資料及刪除影響。若有核銷紀錄（包括作廢紀錄）、已流用紀錄、已鎖定的規劃流用，或刪除會造成經費上限不足，系統會阻止刪除。可刪除時，確認前會列出將一併移除的資料。

4. 核銷紀錄

「核銷紀錄」可新增或編輯核銷明細。每列代表一筆經費明細；多筆明細可共用批次說明及登錄日期。

  • 登錄日期與憑證日期可留白。登錄日期留白時標示「待核銷」，但該筆仍納入經費控管。
  • 日期須符合專案執行期間；憑證日期不可晚於登錄日期。
  • 付款對象及分配金額可不填；若填寫，兩者須成對，分配金額合計須等於核銷金額。
  • 作廢紀錄保留供查核，但不計入有效核銷統計。

若核銷項目沒有相符的預算明細，系統會先詢問是否建立初始預算為 0 元的明細，再儲存核銷。超過專案或相關經費上限時，系統會拒絕儲存。

頁面可依「待核銷」、「已核銷」、「作廢」或「總覽」查看資料，並使用批次「刪除」、「作廢」或「復原」功能。

5. 經費流用

「經費流用」記錄同一專案、同一經費類別內的預算流出與流入，可跨單位或預算科目。新增時依序填寫日期、經費類別、流出項目、流入項目及金額。流用日期須在專案執行期間；已流用資料的流出與流入經費屬性須相同。

  • 規劃中：可先記錄已知資訊。流出項目及正數金額填妥時，系統會圈存可用額度；資料未填齊時不圈存。規劃資料不列入實際經費統計及正式報表。
  • 已流用：須補齊必要資料並通過額度與經費屬性檢查。流出金額不得超過扣除其他規劃圈存後的可用餘額。已流用資料列入總額、流用科目變更及正式報表。

每筆流用的鎖定狀態與「規劃中／已流用」分開管理。已鎖定紀錄不可編輯或刪除。頁面提供「總覽」、「未鎖定」、「已鎖定」及「規劃中」分頁，以及批次刪除、鎖定與解鎖功能。批次解鎖及可能造成預算明細透支的刪除會要求確認；選取項目中若有已鎖定紀錄，刪除會被拒絕。

6. 經費總覽與補充保費估算

經費總覽

首頁與「經費總覽」並列兩種執行率：真實執行率以已填登錄日期且未作廢的核銷金額計算，供報告使用；預估執行率納入所有未作廢核銷金額（含待核銷），用來觀察目前規劃狀況。兩者皆以專案經費總額為分母。依經費類別與屬性表分列流用後預算、已核銷、待核銷、可用餘額及含待核銷執行率，保留「類別小計」；依單位表分列已核銷、待核銷、可用餘額、含待核銷執行率及查看操作。可用餘額＝流用後預算－已核銷－待核銷，執行率＝（已核銷＋待核銷）÷流用後預算，分母為 0 時顯示「—」。每月進度圖依專案執行起訖月份連續呈現真實執行率；待核銷沒有登錄日期，因此不列入月圖。頁面亦提供依經費類別與屬性彙整、依單位彙整、待核銷明細及專案筆記。筆記會儲存在系統資料庫。

補充保費估算

在「補充保費估算」選取要估算的預算科目。系統以所選科目的預算餘額合計乘以共用倍率計算，預設倍率為 2.11%，可調整。估算結果四捨五入至整數元，供預算管理參考。

7. 匯入資料

系統支援 .xlsx、.xlsm 及 .csv 檔案匯入；Excel 檔案讀取第一個工作表。匯入前選擇資料類型並檢查預覽。預覽不會寫入資料；確認匯入後才會新增紀錄。三種匯入共用欄名檢查：空白欄名且整欄無資料時略過；有資料時指出欄位位置。未知欄名、重複欄名、同義欄位衝突或資料列欄數多於表頭時，會顯示錯誤並阻擋匯入。

  • 預算：檢查欄位、選項及預算上限。確認匯入時，資料所需的新選項會同步建立在「選項資料」。
  • 核銷：可選擇每列建立獨立批次，或合併批次說明與登錄日期皆相同且非空白的資料。
  • 流用：正式金額欄名為「流用金額」；檢查流出／流入項目、經費屬性及可用餘額。預覽有錯誤時不可匯入；檔案內有重複資料時，確認後仍可繼續匯入。

8. 匯出報表

在「匯出資料」選擇專案彙總、單位資料或兩者，再選擇 Excel、Markdown 或 PDF。首頁另可依專案狀態匯出專案清單。PDF 會開啟預覽，可使用瀏覽器列印或另存為 PDF。規劃中的流用不納入正式匯出報表。匯出檔定位為精簡報表，不能直接匯回；新增資料請使用匯入範本。流用科目變更匯出為單一 Excel 活頁簿，包含總表及每個經費類別的工作表，依類別、屬性與科目分列並附合計。

9. Email 經費報告

Email 功能位於個別專案內。先設定 SMTP 寄件服務及收件人，再選擇收件對象、設定主管資料範圍、檢視郵件預覽，最後確認寄送。

  • 單位收件人固定收到其所屬單位資料；主管的資料範圍可在寄送時選擇。
  • 每次報告涵蓋專案開始日至寄送當下的累計紀錄，不會按月自動寄送。
  • 每封郵件可附上所選格式的專案報表。寄送結果會逐位記錄；刪除寄送紀錄不會撤回已寄出的郵件。
  • SMTP 設定全系統共用。密碼或應用程式專用密碼儲存在 Windows 安全憑證區，不存於 SQLite。同一 Windows 使用者帳戶下搬移專案資料夾可沿用設定；複製到其他電腦時需在新電腦重新輸入密碼。

提醒：預覽郵件不會實際寄送。只有在檢視內容並確認寄送後，系統才會發出郵件。

10. 資料庫備份與還原

使用側邊欄的「下載資料庫備份」定期備份。還原備份會以備份檔完整取代目前資料；操作前請確認選取的是正確備份檔。搬移到另一台電腦時，請備份並移轉資料庫。不要在系統運作時使用其他程式直接修改資料庫。

11. 表單與畫面操作

  • Ctrl+S：儲存表單。
  • Esc 或「關閉表單」：關閉表單；若有未儲存內容，系統會先詢問。
  • 日期使用西元年格式；金額以新臺幣整數元輸入與保存。
  • 表格可調整每頁筆數；多數表格可點擊標題排序，也可設定欄位對齊。
  • 主題設定可切換淺色或深色、設定自訂顏色、上傳或移除背景圖片，以及更換品牌圖示。

本手冊依目前系統功能與專案說明整理。操作畫面若因版本更新而有差異，請以系統畫面提示為準。
