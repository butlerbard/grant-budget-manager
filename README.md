# 專案經費管理系統

單機、單人使用的經費管理工具，使用 Python、SQLite 與本機瀏覽器介面，管理專案預算、核銷、經費流用、報表及 Email 報告。

## 快速開始

- **需求：**Windows 電腦需安裝 Python 3.8 或更新版本。啟動流程會在專案資料夾建立專用 `.venv` 環境。
- **啟動：**雙擊「啟動經費管理.bat」，系統會開啟本機瀏覽器；關閉啟動程式的命令視窗即可停止服務。
- **選用功能：**PDF 匯出／附件需要 PDF 套件組；Email 寄送需要 `keyring`。安裝或更新方式見[開發維護參考](SYSTEM_REFERENCE.md#系統需求與啟動)。

## 初次使用

1. 建立專案；系統會建立部分預設選項。
2. 到「選項資料」確認選項，視需要補充。
3. 匯入預算；資料中需要的新選項會同步建立。也可手動新增預算。
4. 核對「預算明細」，再開始登錄核銷與流用。

## 功能

專案與預算管理、核銷與經費流用、經費總覽及補充保費估算、預算／核銷／流用資料匯入、Excel／Markdown／PDF 報表、Email 經費報告，以及資料庫備份與還原。
